# CHANGELOG — DS3 Co-op

## 2026-10-24 (ночь, 01:28) — Этап 5.1: исправлены два дефекта диагностики

**Повод:** восстановление контекста показало, что инструменты собраны, но ни разу
не запускались (лога нет). При чтении кода найдены два дефекта, которые проявились
бы именно на первом запуске с настоящей игрой.

**Дефект 1 — работа внутри `DllMain`.** Диагностика выполнялась прямо в `DllMain`,
где Windows держит блокировку загрузчика. Долгая работа там подвешивает старт игры.
Исправлено: в `DllMain` осталось открытие лога и `CreateThread`, вся работа
перенесена в `Worker`.

**Дефект 2 — `VirtualQuery` на каждый байт.** Поиск строки шёл побайтово по образу
игры (87 МБ), на каждой позиции вызывался `VirtualQuery` — 87 миллионов вызовов.
**Замерено** на Windows (`QueryPerformanceCounter`, 1 000 000 вызовов):
`0.821 мкс` на вызов → **≈71 секунда** на проход. Исправлено: обход памяти
регионами, один `VirtualQuery` на регион.

**Замер после исправления:** поиск по буферу 256 МБ — **966 МБ/с**,
образ игры 87 МБ проходится примерно за **90 мс**.

**Затронутые файлы:**
- `patches/ds3coop-tools/src/ds3coop_tools.cpp` — переписан (скан + поток + замеры)
- `patches/ds3coop-tools/build/ds3coop_tools.dll` — пересобран,
  SHA-256 `6575a9c457ccb8d8dd933348e536c4f6d60184722739a161d72294afe268429e`
- `patches/ds3coop-tools/README.md` — описание исправлений и замеров
- `STATE.md`, `TODO.md` — обновлены

**Проверено:** сборка без предупреждений (`-Wall -Wextra`), зависимости только
`KERNEL32.dll` и `msvcrt.dll`; загрузка DLL в служебный процесс Windows успешна,
лог создаётся; отсутствие игры даёт `ИТОГ: FAIL (игра не загрузилась)`.
Временные тестовые файлы удалены.

**Не проверено:** запуск с настоящей игрой.

**В игре пока СТАРАЯ версия DLL.** Новая лежит только в `patches/build/`.

**Проверено:** DLL грузится, лог создаётся, отсутствие игры обрабатывается
корректно (`ИТОГ: FAIL (игра не загрузилась)`), лаунчер без игры отказывается
запускаться. Установлены в `Game\` и `Game\SeamlessCoop\`.

**Не проверено:** запуск с настоящей игрой. Нужен запуск владельцем.

**Анализ мода:** подтверждено, что `ds3sc.dll` резолвит адреса функций игры

делать в живой игре, а не только по файлу.
