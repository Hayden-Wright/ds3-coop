## 1. Души — проверка

**Тест:** гость стоит рядом, хост убивает обычного моба.

- [ ] Хост убил моба
- [ ] Души у хоста изменились на: ______
- [ ] Души у гостя изменились на: ______

**Вопрос:** изменились ли души у гостя? ДА / НЕТ

**Тест 2 (наоборот):** гость убивает моба.

- [ ] Души у гостя: ______
- [ ] Души у хоста: ______

**Вопрос:** изменились ли души у хоста? ДА / НЕТ

**Тест 3 (босс, если дойдёт):**
- [ ] Души хоста после босса: ______
- [ ] Души гостя после босса: ______

**Вывод:** пункт 1 — РАБОТАЕТ / ЧАСТИЧНО / НЕ РАБОТАЕТ

## 2. Лут — проверка

**Тест:** найти предмет на земле (не в сундуке), подобрать.

- [ ] Гость подобрал предмет: ______________________
- [ ] Хост видит тот же предмет на земле? ДА / НЕТ
- [ ] Хост подобрал его: ______________________
- [ ] Оба видят предмет в своём инвентаре? ДА / НЕТ

**Тест 2:** предмет, выдаваемый диалогом NPC (например, кольцо Грейрата).

- [ ] Что за предмет: ______________________
- [ ] Получил хост? ДА / НЕТ
- [ ] Получил гость? ДА / НЕТ

**Вывод:** пункт 2 — РАБОТАЕТ / ЧАСТИЧНО / НЕ РАБОТАЕТ
