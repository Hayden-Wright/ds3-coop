# План: что делаем к приходу друга

Дата: 2026-10-24. Друг придёт вечером 2026-10-25.

## Честная оценка

Из четырёх требований:

| # | Требование | Реальное состояние | Нужна работа? |
|---|---|---|---|
| 1 | Души обоим | **скорее всего уже работает** — призванный игрок получает души за убийства в чужом мире | проверить за 2 минуты |
| 2 | Лут каждому | **работает для предметов с земли** (инстансированы), частично для скриптовых выдач | проверить |
| 3 | Свои торговцы/NPC | **сломано** — подтверждено в игре: гость не смог прокачать фляски | **да, основная работа** |
| 4 | Индивидуальные траты | работает по устройству (разные персонажи, разные сейвы) | проверить |

**Главный вывод: реальная работа — только пункт 3.** Остальное либо уже есть,
либо требует проверки, а не кода.

## Почему пункт 3 сложный

В Seamless Co-op NPC существуют в мире **хоста**. Гость видит того же Андре,
того же торговца — но это не его NPC. Их ассортимент и прогресс привязаны к хосту.

Чтобы гость мог качать фляски и торговать сам, нужно одно из двух:

**Вариант A. Свои NPC для гостя.** Гость получает собственные копии NPC со своим
прогрессом. Технически тяжело: нужно развести состояние NPC по игрокам и не сломать
синхронизацию мира.

**Вариант B. Меню гостя без NPC.** Гость открывает свой интерфейс прокачки/торговли
(как будто он у себя), не подходя к NPC. Легче: не трогаем мир, только UI и данные
персонажа.

Вариант B выглядит реалистичнее для первого шага.

## Что мешает прямо сейчас

1. **Нет компилятора C++.** Ни в WSL, ни в Windows (Visual Studio и Windows SDK
   не установлены). Без него DLL не собрать.
   - В apt есть `gcc-mingw-w64-x86-64-posix` (~35 МБ). Требует `sudo` —
     команду должен выполнить владелец.
2. **Нельзя проверить до вечера.** Второго клиента нет. Значит, код, написанный
   вслепую, останется непроверенным до прихода друга.
3. **Мод — закрытый бинарник.** Своих исходников нет. Смещения функций придётся
   брать из открытых проектов (Ashen Link) или искать самим.

## Что реально успеть к вечеру 25 октября

### Обязательно (без этого встреча пройдёт впустую)

- [ ] **Чек-лист проверки** — что именно смотреть в игре, по пунктам.
      Готовим сейчас, чтобы за 10 минут сессии получить все ответы.
- [ ] **Проверка душ** — убить моба, сравнить счётчики у хоста и гостя.
- [ ] **Проверка костра** — какие пункты меню у гостя активны, какие серые.
- [ ] **Проверка торговца** — может ли гость открыть магазин и купить.
- [ ] **Проверка прокачки у Хранительницы** — может ли гость повысить уровень.
- [ ] **Записать результаты** в `notes/03-live-test.md`.

### Если получится

- [ ] Поставить компилятор (владелец выполняет команду с `sudo`).
- [ ] Собрать каркас DLL-прослойки: загрузка, лог, проверка идентичности игры.
      Это уже проверяемо без второго игрока.
- [ ] Найти в игре функцию, отвечающую за меню прокачки у костра.

### Чего НЕ обещаю

**Готового патча к вечеру не будет.** Причины: нет компилятора, нет возможности
тестировать до вечера, мод закрытый. Обещать «сделаю к завтра» было бы обманом.

Реалистичная цель: **к вечеру точно знать, что именно сломано и как это чинить**,
плюс иметь каркас для патча.

## Порядок действий на завтрашнюю сессию

1. Встречаемся в игре, проходим чек-лист (10–15 минут).
2. Записываем результаты в `notes/03-live-test.md`.
3. По результатам выбираем вариант A или B для пункта 3.
4. Дальше — разработка патча, уже с возможностью проверять.

## Важно про безопасность

- Играем только в кооп-режиме мода, на сохранениях `.co2`.
- Античит не трогаем, к серверам FromSoftware не подключаемся.
- Патч ставится отдельным пакетом, файлы автора не правим.
